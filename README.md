# douyin-downloader

A Douyin video downloader skill for OpenClaw/AgentSkills.

## Installation

```bash
npx skills add <your-username>/douyin-downloader
```

## Features

- Download no-watermark videos from Douyin.
- Uses Playwright for robust page rendering and WAF bypass.

## Dependencies

- Python 3.10+
- Playwright
- aiohttp

```bash
pip install playwright aiohttp
playwright install chromium
```
